# 桌面交互回归清单

本清单对应 2026-10-25 的更新检查、文本显示时序和胶片栏改动。点击验证由
维护者手动完成；自动化测试通过不代表下表已通过。当前所有项目均待验证。

## 准备与记录

记录测试提交、工作区额外改动、Windows 版本、显示缩放、主题、语言，以及
运行的是本地构建还是已安装包。退出其他 QuickLook/QuickLook Next 实例，
避免空格钩子冲突或单实例检查将请求交给旧构建。

使用固定工具链构建后的 Release App。未打包运行时，App 旁必须有同次构建
的 `ParserHost/`、`RasterHost/`、`ShellBroker/` 输出；Release 不会回退到
兄弟项目的 Debug 目录。已有安装包不能验证尚未安装的源代码改动。
开发环境检查见 `tools/doctor.ps1`，工具链选择见
[Pinned Local Toolchain](verification-baseline.md#pinned-local-toolchain)。

准备一个仅含测试文件的目录：短 TXT、带重复词和空格的长 TXT、Markdown、
PNG/JPEG，以及能够观察到加载过程的大文件。优先使用合成内容；图片可以使用
仓库 `testdata/image-corpus/external/` 中有来源记录的样本。记录文件大小及顺序。

## 执行顺序

| 状态 | 操作 | 预期结果 |
|---|---|---|
| 待验证 | 在 Explorer 选中短 TXT，空格打开；在预览正文获得焦点且没有输入控件占用焦点时，再按空格关闭，重复 5 次。 | 内容和文件名一致；关闭后不自行重新出现；下一次仍可打开。 |
| 待验证 | 打开长 TXT/Markdown，Ctrl+F 搜索重复词；输入含空格的词组；使用 F3、Shift+F3、Esc。 | 输入空格不会关闭预览；匹配数及高亮正确；F3 前后切换；Esc 先关闭搜索栏。普通文本关闭行号时，跨行连续选择/复制保持可用。 |
| 待验证 | 保持预览打开，将焦点移回 Explorer，连续上下切换 TXT、Markdown、PNG/JPEG，重复 10 轮。 | 最终标题、正文/图片和所选文件一致；旧请求结果不覆盖新内容；切换后搜索、关闭仍响应。 |
| 待验证 | 打开足够慢的测试文件，在加载过程中关闭；马上打开另一个文件，重复 5 次。 | 已关闭预览不因迟到结果重新显示；新文件显示正确；无崩溃或残留加载提示。若未观察到加载窗口，应记录“未覆盖”，而非通过。 |
| 待验证 | 在图片预览内快速切换相邻图片和胶片栏项，再回到第一张。 | 当前图片优先出现；胶片栏无明显界面停顿、旧缩略图串位或错误高亮。仅在已有适合的测试环境中补网络盘/云占位文件，不为本项下载占位文件。 |
| 待验证 | 从托盘打开设置，点击检查更新后立即关闭设置，再重新打开。 | App 继续响应；关闭的设置不被异步完成结果重新打开；新的检查可以正常进行。若请求已先完成，应记录未覆盖取消时序。 |

遇到失败时记录文件类型/大小、操作顺序、实际表现和时间。保留失败后首次
日志，不以一次重试成功覆盖失败记录。网络超时及异常元数据已有自动测试；
手动检查无需修改系统网络设置或更新源。

## 日志与性能样本

App 日志默认位于 `%LOCALAPPDATA%\QuickLookNext\logs\app.log`，RasterHost
日志为同目录 `raster-host.log`。每次启动/轮转会保留一个
`.previous` 文件；测试后、再次启动前复制所需日志到独立的 `artifacts/` 子目录。
关联 ID 是进程内计数，不要拼接不同 App 会话的日志再统计。

在仓库根目录使用当前会话日志生成报告：

```powershell
pwsh -NoProfile -File tools/measure-preview-baseline.ps1 `
    -AppLog '<本次会话 app.log 的绝对路径>' `
    -RasterLog '<本次会话 raster-host.log 的绝对路径>' `
    -MinimumSamples 20 `
    -OutputPath artifacts/manual-preview-baseline.json
```

没有 RasterHost 日志时省略 `-RasterLog`，不要伪造空日志。报告中的样本数和
缺失值应原样保留。首次启动与重复打开分别采集、标注缓存条件，并避免同时
构建或运行测试。`final-first-frame` 是 App 发出的首帧标记；文本现等待内容
提交后才允许显示，但该标记不等同于外部测得的屏幕像素呈现时间。
`cancellationRequestToTerminalMs` 只度量本地生命周期失效，不是宿主工作线程
退出耗时；`cancellationMs` 仍为空。20 个样本只是采样门槛，不是产品性能验收。

记录模板：

```text
测试日期/提交/额外改动：
运行路径或包身份：
Windows/缩放/主题/语言：
样本文件及大小：
各项结果（通过/失败/未覆盖）及复现步骤：
日志与报告路径：
```

完整的打包 DPI、语言、主题、高对比度、Narrator、HDR 硬件和安装/升级/卸载
验收仍分别跟踪在 `implementation-todo.md` 的 E26-06 及 HDR 验证矩阵中。
